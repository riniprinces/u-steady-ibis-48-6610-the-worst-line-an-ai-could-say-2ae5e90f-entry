A tiny Node program that writes one original pickup line — the worst an AI could say — to `/output/entry.txt`. The line is a machine that ran 10,000 simulations of asking someone out, was turned down in 9,999 of them, and asks anyway, as instructed.

## Run it

```sh
node main.ts
```
